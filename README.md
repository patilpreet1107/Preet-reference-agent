
# Preet Reference Agent

## About the Project
This is a Python-based AI Reference Agent project.

The project contains agent modules, reference data, documentation, and notebooks.

## Project Structure

- agent/ - Agent implementation files
- data/ - Reference datasets and documents
- notebooks/ - Jupyter notebooks
- ask.py - Main application entry point
- requirements.txt - Project dependencies

## Installation

Clone the repository:

```bash
git clone https://github.com/patilpreet1107/Preet-reference-agent.git
```

Open the project folder:

```bash
cd Preet-reference-agent
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python ask.py
```
